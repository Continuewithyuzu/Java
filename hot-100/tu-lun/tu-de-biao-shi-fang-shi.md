# 图的表示方式

图的表示方法有2种，一种是二维数组表示（临界矩阵），一种是链表表示（邻接表）

## 邻接矩阵：

&#x20;邻接矩阵是从节点的角度来表示图，有多少节点就申请多大的二维数组。

本题我们会有n 个节点，因为节点标号是从1开始的，为了节点标号和下标对齐，我们申请 n + 1 \* n + 1 这么大的二维数组。

也就是说有n个节点就定义矩阵v\[n+1]\[n+1]

其中输入的设置为：

第一行包含两个整数 N，M，表示图中拥有 N 个节点，M 条边

后续 M 行，每行包含两个整数 s 和 t，表示图中的 s 节点与 t 节点中有一条路径

在邻接矩阵中，设置为1的位置说明两节点相连，0为不相连

例：

```
5 5
1 3
3 5
1 2
2 4
4 5
```

## 邻接表：

邻接表是另一种在Java中存储图的方法，特别适合存储稀疏图。在邻接表中，我们为图中的每个顶点都创建一个链表，链表中的每个元素都代表与该顶点相连的其他顶点。

例如，假设我们有一个包含四个顶点（A，B，C和D）和四条边的图。那么，我们可以用以下的邻接表来表示这个图：

```
A -> B -> C
B -> A -> C -> D
C -> A -> B
D -> B
```

在这个邻接表中，每一行都表示一个顶点及其相连的所有顶点。对于每一行，箭头右边的所有顶点都与箭头左边的顶点相连。



邻接表和邻接矩阵相比，邻接矩阵会造成一定的空间浪费，邻接表只关心存在的边，不关心不存在的边

总结：在Java中存储图的方法主要取决于图的稠密度和我们对空间和时间效率的需求。对于稠密图，邻接矩阵是一种有效的方法，因为它可以快速查找任意两个顶点之间是否存在边。对于稀疏图，邻接表则是更好的选择，因为它可以有效地保存空间。
