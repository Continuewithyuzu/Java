# 数据范围



> 1\. **`int` 类型**
>
> * **取值范围**：`-2^31` 到 `2^31 - 1`，即 `-2147483648` 到 `2147483647`。
> * **最大值**：`2147483647`（约等于 `10^9`）。
> * **适用场景**：适用于大多数整数运算，特别是数值在 `-2147483648` 到 `2147483647` 之间时。
>
> #### 2. **`long` 类型**
>
> * **取值范围**：`-2^63` 到 `2^63 - 1`，即 `-9223372036854775808` 到 `9223372036854775807`。
> * **最大值**：`9223372036854775807`（约等于 `10^19`）。
> * **适用场景**：当数值超出 `int` 类型范围但仍然适合存储在 64 位整数中时使用。
>
> #### 3. **`BigInteger` 类型**
>
> * **取值范围**：无固定范围，`BigInteger` 可表示任意大小的整数。
> * **适用场景**：当需要处理超大整数（大于 `long` 范围）时使用，如 `10^20` 或更大的数字。
